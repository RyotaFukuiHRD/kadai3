  <section class="intro" id="appeal">
    <p class="eyebrow">01 / WHY PADEL?</p>
    <h2>パデルの魅力</h2>
    <p class="lead">パデルは、壁に囲まれたコートでプレーするラケットスポーツ。ボールが壁に当たってからも続けられるので、ラリーの展開が読めないのが面白さです。</p>
    <div class="feature-grid">
      <article class="feature-card"><span class="card-number">01</span><h3>ラリーが続いて楽しい</h3><p>壁を使った返球ができるため、思いがけない方向からボールが戻ってきます。</p></article>
      <article class="feature-card"><span class="card-number">02</span><h3>ダブルスが基本</h3><p>基本はペアでプレー。声を掛け合いながら、作戦を考える楽しさがあります。</p></article>
      <article class="feature-card"><span class="card-number">03</span><h3>初めてでも始めやすい</h3><p>コートが比較的コンパクトで、ラケットスポーツの経験がなくても挑戦しやすい競技です。</p></article>
    </div>
  </section>

  <section class="rules-preview" id="basics">
    <div>
      <p class="eyebrow">02 / THE BASICS</p>
      <h2>まずは基本ルール</h2>
      <p>得点の数え方はテニスと同じく、0・15・30・40・ゲーム。サーブは腰より低い位置で打ち、ボールを相手コートに入れます。ラリー中は自分のコートに一度バウンドしたボールを打ち返し、壁を使うこともできます。</p>
      <a class="text-link" href="rules.html">テニスとの違いも読む <span aria-hidden="true">→</span></a>
    </div>
    <aside class="fact-box"><span class="fact-icon" aria-hidden="true">↗</span><p>壁に当たったボールも、床に2回つく前ならプレーを続けられます。</p></aside>
  </section>
