  <section class="intro" id="appeal">
    <p class="eyebrow">01 / WHY PICKLEBALL?</p>
    <h2>ピックルボールの魅力</h2>
    <p class="lead">ピックルボールは、テニス・卓球・バドミントンの要素をあわせ持つアメリカ生まれのラケットスポーツ。「パドル」と呼ばれる板状のラケットで、穴のあいたプラスチック製のボールを打ち合います。</p>
    <div class="feature-grid">
      <article class="feature-card"><span class="card-number">01</span><h3>ラリーが続いて楽しい</h3><p>穴のあいたボールはスピードが出にくく、弾みもゆるやか。初めてでもラリーが続きやすく、すぐにゲームを楽しめます。</p></article>
      <article class="feature-card"><span class="card-number">02</span><h3>子どもからシニアまで</h3><p>ダブルスが主流で、力よりも配球や駆け引きが大切。年齢や体力に差があっても、同じコートで一緒にプレーできます。</p></article>
      <article class="feature-card"><span class="card-number">03</span><h3>日本でも始めやすい</h3><p>コートはバドミントンのダブルスと同じ広さ。体育館のバドミントンコートを活用でき、各地で体験会も開かれています。</p></article>
    </div>
  </section>

  <section class="rules-preview" id="basics">
    <div>
      <p class="eyebrow">02 / THE BASICS</p>
      <h2>まずは基本ルール</h2>
      <p>サーブは下から、腰より低い位置で打ち、対角線上の相手コートへ入れます。サーブとそのリターンは、どちらもワンバウンドさせてから打つのが決まり。得点が入るのはサーブ側だけで、1ゲームは11点先取、2点差をつけたほうの勝ちです。</p>
      <a class="text-link" href="rules.html">テニスとの違いも読む <span aria-hidden="true">→</span></a>
    </div>
    <aside class="fact-box"><span class="fact-icon" aria-hidden="true">↗</span><p>ネット前のゾーン「キッチン」の中では、ノーバウンドで打つボレーができません。</p></aside>
  </section>
